# CrossWorld DEV BASE 0.3 실행 테스트

## 테스트 대상

- 기준 버전: **CrossWorld DEV BASE 0.3**
- 실행 파일: `Emuera.NET 1824+v24+EMv18+EEv56.exe`
- 오프닝 스킵: 각 프레임의 `[0] 오프닝 스킵`을 숫자키 또는 마우스로 선택

전체 디렉터리를 한 위치에 압축 해제한 뒤 위 EXE를 직접 실행한다. 실제 Emuera 실행 확인 전에는 PASS로 판정하지 않는다.

## A. 오프닝

1. 거의 비어 있는 화면과 작은 빛에서 시작하는지 확인한다.
2. 흩어진 별이 여러 프레임에 걸쳐 중앙으로 수렴하는지 확인한다.
3. 중앙의 빛으로 합쳐지는 연출을 확인한다.
4. 달, 산맥, 첨탑과 지평선으로 구성된 세계 풍경이 나타나는지 확인한다.
5. 대형 `CROSSWORLD` 로고가 나타나는지 확인한다.
6. 최종 타이틀 메뉴가 표시되는지 확인한다.
7. 재생 도중 `[0]` 키 또는 `[0] 오프닝 스킵` 클릭으로 즉시 최종 타이틀로 이동하는지 확인한다.
8. 프레임 속도, 깜빡임과 전체 재생 시간이 불편하지 않은지 확인한다.

## B. 화면

- 풍경과 로고가 창 너비에서 잘리지 않는지 확인한다.
- ASCII 정렬이 심하게 깨지지 않는지 확인한다.
- 한글이 정상 출력되는지 확인한다.
- 대형 로고가 `CROSSWORLD`로 명확히 읽히는지 확인한다.
- 풍경, 로고와 메뉴의 간격이 자연스러운지 확인한다.

## C. 타이틀 입력

- `[1] 게임 시작`: 새 게임이 HOME, `1일 08:00`에서 시작하는지 확인한다.
- `[2] 로드`: “로드 기능은 아직 사용할 수 없습니다.” 안내 후 타이틀로 복귀하는지 확인한다.
- `[3] 종료`: 게임이 정상 종료되는지 확인한다.
- 세 항목 모두 키보드 숫자 입력과 마우스 클릭을 각각 확인한다.
- 잘못된 입력 후 안내가 표시되고 타이틀 메뉴가 유지되는지 확인한다.

## D. DEV BASE 0.2 회귀 테스트

1. HOME에서 `1일 08:00`을 확인한다.
2. HOME → PLAZA: `08:10`
3. PLAZA → SHOP: `08:20`
4. SHOP → PLAZA: `08:30`
5. PLAZA → PARK: `08:40`
6. PARK → PLAZA: `08:50`
7. PLAZA → STATION: `09:00`
8. STATION → PLAZA: `09:10`
9. PLAZA → HOME: `09:20`
10. HOME에서 잠자기 후 `2일 08:00`을 확인한다.

추가로 이동 불가능한 장소와 잘못된 입력이 위치·시간을 변경하지 않는지 확인한다.

## 결과 처리

- 실제 Emuera 실행에서 모든 필수 항목을 확인한 경우에만 PASS로 판단한다.
- FAIL이면 `game/`을 직접 수정하지 않고 `dev/runtime/`에서 수정한다.
- PASS 후 별도 승격 작업으로 검증된 변경만 `game/`에 반영한다.
