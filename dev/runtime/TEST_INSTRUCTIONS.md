# CrossWorld DEV BASE 0.3 오프닝 REV5 실행 테스트

## 테스트 대상

- 기준 버전: **CrossWorld DEV BASE 0.3**
- 실행 파일: `Emuera.NET 1824+v24+EMv18+EEv56.exe`
- 오프닝: 총 36프레임, 별 이동 프레임당 60ms
- 별 이동 가상 화면: 144열 × 24행
- 최종 타이틀: 144열 기준 폭 × 50행 구성(크기 유지, 미술 품질 개선)
- 스킵: 오프닝 중 숫자키 `0` 또는 `[0] SKIP` 클릭

실제 Emuera 실행 확인 전에는 PASS로 판정하지 않는다.

## A. SPACE OUTPUT CHECK

1. 첫 화면의 결과가 정확히 `*     *`인지 확인한다.
2. 두 별 사이에 실제 공백 5칸만 보이는지 확인한다.
3. 따옴표, 변수 이름 또는 ERB 명령문이 보이지 않는지 확인한다.
4. 아무 키나 눌러 다음 검증 화면으로 진행한다.

## B. 정적 1프레임 좌표 렌더링

1. 약 40열 × 9행 영역의 서로 다른 좌표에 `*`, `+`, `.`, `o`, `O`가 표시되는지 확인한다.
2. 빈 부분이 따옴표나 반복 문자 없이 완전히 빈 공간으로 보이는지 확인한다.
3. 변수 이름이나 ERB 명령문이 보이지 않는지 확인한다.
4. 아무 키나 눌러 본 오프닝을 시작한다.

## C. 오프닝 품질

1. 오프닝이 최소 30프레임 이상으로 보이는지 확인한다.
2. 흩어진 14개 별이 중앙으로 부드럽게 이동하는지 확인한다.
3. 이전 9프레임 버전보다 움직임이 명확히 자연스러운지 확인한다.
4. 별 수렴 전체 시간이 지나치게 길거나 짧지 않은지 확인한다.
5. 중앙 합체, 빛의 확장, 세계 윤곽, 완성 타이틀 순서가 자연스러운지 확인한다.
6. 프레임 전환 중 깜빡임이 과도하지 않은지 확인한다.
7. 별들이 작은 중앙 구역에 몰리지 않고 144열 × 24행 범위 전체에서 출발하는지 확인한다.

## D. 출력 안전성

- 화면에 `PRINTL`, `CALL`, `RETURN`, `IF`, `ENDIF` 같은 ERB 명령문이 나타나지 않는지 확인한다.
- 화면에 변수 이름이나 문자열 연결식이 문자 그대로 나타나지 않는지 확인한다.
- 공백과 별 문자가 `" "`, `"*"`, `"O"`처럼 따옴표를 포함해 보이지 않는지 확인한다.
- 빈 셀은 출력하지 않고 별 앞의 간격만 폭 지정 포맷으로 생성하므로, 화면 전체에 반복 문자가 생기지 않는지 확인한다.
- 백슬래시나 전각 엔화 기호 형태의 깨진 문자가 나타나지 않는지 확인한다.
- ASCII가 창 너비를 초과하거나 좌우로 조각나지 않는지 확인한다.
- 한글 메뉴와 안내가 정상 출력되는지 확인한다.

## E. 최종 타이틀 화면

- 비대칭 표면 디테일이 추가된 거대한 천체를 알아볼 수 있는지 확인한다.
- 산맥이 단순한 `^` 반복이 아니라 좌우 비대칭의 다양한 높이로 보이는지 확인한다.
- 중앙 주탑이 좌우 부탑보다 높고 성벽·창문·문이 하나의 성 실루엣으로 연결되는지 확인한다.
- 10행, 약 130열 대형 로고가 `CROSSWORLD`로 즉시 읽히는지 확인한다.
- 전체 타이틀이 REV4와 같은 144열 규모를 유지하는지 확인한다.
- 풍경, 로고, 메뉴가 하나의 중앙 타이틀 구도로 보이는지 확인한다.
- 개발 버전 문구가 화면 맨 아래에서 타이틀 구도를 방해하지 않는지 확인한다.
- 숫자키 `0`과 스킵 표시 클릭이 모두 동작하는지 확인한다.

## F. 타이틀 메뉴

- `[1] 게임 시작`: HOME, `1일 08:00`으로 진입
- `[2] 로드`: 미구현 안내 후 타이틀 복귀
- `[3] 종료`: 정상 종료
- 키보드 숫자와 마우스 클릭을 각각 확인한다.
- 잘못된 입력 후 타이틀 메뉴가 유지되는지 확인한다.

## G. DEV BASE 0.2 회귀 테스트

1. HOME → PLAZA: `08:10`
2. PLAZA → SHOP: `08:20`
3. SHOP → PLAZA: `08:30`
4. PLAZA → PARK: `08:40`
5. PARK → PLAZA: `08:50`
6. PLAZA → STATION: `09:00`
7. STATION → PLAZA: `09:10`
8. PLAZA → HOME: `09:20`
9. HOME에서 잠자기 후 `2일 08:00`

이동 불가능한 장소와 잘못된 입력이 위치·시간을 변경하지 않는지도 확인한다.

## 결과 처리

- 모든 최종 판정은 사용자의 실제 Emuera 실행 결과를 따른다.
- FAIL이면 `game/`을 수정하지 않고 `dev/runtime/`에서 다시 수정한다.
- PASS 후 별도 작업으로 검증된 변경만 `game/`에 승격한다.
