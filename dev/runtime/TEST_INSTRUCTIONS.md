# CrossWorld DEV BASE 0.2 실행 테스트

## 테스트 대상

- 기준 버전: **CrossWorld DEV BASE 0.2**
- 실행 파일: `Emuera.NET 1824+v24+EMv18+EEv56.exe`
- 실행 환경 기준: `test/ERA_CrossWorld_Runtime_Test_0.1.2/`

이 디렉터리는 현재 개발 중인 코드를 실제 Emuera에서 확인하기 위한 가변 작업장이다. 압축 파일로 내려받았다면 전체 내용을 한 디렉터리에 압축 해제한 뒤 위 EXE를 직접 실행한다.

## 필수 이동 시나리오

1. 게임을 실행하고 HOME에서 `1일 08:00`을 확인한다.
2. `[2] 나간다`를 선택하고 PLAZA에서 `1일 08:10`을 확인한다.
3. PLAZA에서 `[2] 상점`을 선택하고 SHOP에서 `1일 08:20`을 확인한다.
4. SHOP에서 `[1] 광장`을 선택하고 PLAZA에서 `1일 08:30`을 확인한다.
5. PLAZA에서 `[4] 공원`을 선택하고 PARK에서 `1일 08:40`을 확인한다.
6. PARK에서 `[1] 광장`을 선택하고 PLAZA에서 `1일 08:50`을 확인한다.
7. PLAZA에서 `[3] 역`을 선택하고 STATION에서 `1일 09:00`을 확인한다.
8. STATION에서 `[1] 광장`을 선택하고 PLAZA에서 `1일 09:10`을 확인한다.
9. PLAZA에서 `[0] 자택`을 선택하고 HOME에서 `1일 09:20`을 확인한다.
10. HOME에서 `[1] 잔다`를 선택하고 `2일 08:00`을 확인한다.

## 화면과 연결 확인

- ASCII MAP에 `HOME - PLAZA - PARK`, `PLAZA - SHOP`, `PLAZA - STATION` 연결이 보이는지 확인한다.
- 맵의 현재 위치 표시가 실제 도착 장소와 일치하는지 확인한다.
- HOME, SHOP, PARK, STATION에서는 PLAZA 방향만 이동 가능하고, PLAZA에서는 네 연결 장소만 이동 가능한지 확인한다.

## 입력과 오류 확인

- 키보드 숫자 입력과 화면 숫자 선택지의 마우스 클릭을 각각 확인한다.
- SHOP에서 `[4]` 등 연결되지 않은 장소 번호를 입력해도 순간이동하지 않는지 확인한다.
- 이동 불가능하거나 잘못된 입력 후 현재 위치와 시간이 유지되는지 확인한다.
- 잘못된 입력으로 크래시나 화면 파손이 발생하지 않고 현재 선택 화면이 다시 표시되는지 확인한다.
- HOME 수면 시 날짜가 1 증가하고 시각이 `08:00`으로 돌아오는지 확인한다.

## 자정 넘김 확인

일반 필수 시나리오에서는 자정에 도달하지 않는다. 향후 장시간 반복 이동을 시험할 경우 `23:50`에서 한 구간 이동 후 다음 날 `00:00`으로 바뀌는지 확인한다.

## 결과 처리

- 실제 Emuera 실행에서 모든 필수 항목을 확인한 경우에만 PASS로 판단한다.
- FAIL이면 `game/`을 직접 수정하지 않고 이 `dev/runtime/` 작업장에서 먼저 수정한다.
- PASS 후 별도 승격 작업으로 검증된 CSV/ERB 변경만 `game/`에 반영한다.
