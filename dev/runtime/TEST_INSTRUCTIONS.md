# CrossWorld DEV BASE 0.3 오프닝 REV3 실행 테스트

## 테스트 대상

- 기준 버전: **CrossWorld DEV BASE 0.3**
- 실행 파일: `Emuera.NET 1824+v24+EMv18+EEv56.exe`
- 오프닝: 총 36프레임, 별 이동 프레임당 60ms
- 별 이동 가상 화면: 109열 × 20행
- 최종 타이틀: 약 100열 폭 × 38행 구성
- 스킵: 오프닝 중 숫자키 `0` 또는 `[0] SKIP` 클릭

실제 Emuera 실행 확인 전에는 PASS로 판정하지 않는다.

## A. 오프닝 품질

1. 오프닝이 최소 30프레임 이상으로 보이는지 확인한다.
2. 흩어진 14개 별이 중앙으로 부드럽게 이동하는지 확인한다.
3. 이전 9프레임 버전보다 움직임이 명확히 자연스러운지 확인한다.
4. 별 수렴 전체 시간이 지나치게 길거나 짧지 않은지 확인한다.
5. 중앙 합체, 빛의 확장, 세계 윤곽, 완성 타이틀 순서가 자연스러운지 확인한다.
6. 프레임 전환 중 깜빡임이 과도하지 않은지 확인한다.
7. 별들이 작은 중앙 구역에 몰리지 않고 109열 × 20행 범위 전체에서 출발하는지 확인한다.

## B. 출력 안전성

- 화면에 `PRINTL`, `CALL`, `RETURN`, `IF`, `ENDIF` 같은 ERB 명령문이 나타나지 않는지 확인한다.
- 화면에 `CW_OPENING_LINE + CW_OPENING_PIXEL` 또는 변수명이 문자 그대로 나타나지 않는지 확인한다.
- 백슬래시나 전각 엔화 기호 형태의 깨진 문자가 나타나지 않는지 확인한다.
- ASCII가 창 너비를 초과하거나 좌우로 조각나지 않는지 확인한다.
- 한글 메뉴와 안내가 정상 출력되는지 확인한다.

## C. 최종 타이틀 화면

- 상단의 거대한 천체, 화면 전체에 걸친 산맥, 중앙의 대형 성과 수평선을 알아볼 수 있는지 확인한다.
- 8행 대형 로고가 `CROSSWORLD`로 즉시 읽히는지 확인한다.
- 풍경, 로고, 메뉴가 하나의 중앙 타이틀 구도로 보이는지 확인한다.
- 개발 버전 문구가 화면 맨 아래에서 타이틀 구도를 방해하지 않는지 확인한다.
- 숫자키 `0`과 스킵 표시 클릭이 모두 동작하는지 확인한다.

## D. 타이틀 메뉴

- `[1] 게임 시작`: HOME, `1일 08:00`으로 진입
- `[2] 로드`: 미구현 안내 후 타이틀 복귀
- `[3] 종료`: 정상 종료
- 키보드 숫자와 마우스 클릭을 각각 확인한다.
- 잘못된 입력 후 타이틀 메뉴가 유지되는지 확인한다.

## E. DEV BASE 0.2 회귀 테스트

1. HOME → PLAZA: `08:10`
2. PLAZA → SHOP: `08:20`
3. SHOP → PLAZA: `08:30`
4. PLAZA → PARK: `08:40`
5. PARK → PLAZA: `08:50`
6. PLAZA → STATION: `09:00`
7. STATION → PLAZA: `09:10`
8. PLAZA → HOME: `09:20`
9. HOME에서 잠자기 후 `2일 08:00`

이동 불가능한 장소와 잘못된 입력이 위치·시간을 변경하지 않는지도 확인한다.

## 결과 처리

- 모든 최종 판정은 사용자의 실제 Emuera 실행 결과를 따른다.
- FAIL이면 `game/`을 수정하지 않고 `dev/runtime/`에서 다시 수정한다.
- PASS 후 별도 작업으로 검증된 변경만 `game/`에 승격한다.
