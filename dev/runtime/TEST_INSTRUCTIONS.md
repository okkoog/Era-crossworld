# CrossWorld DEV BASE 0.1 실행 테스트

## 테스트 대상

- 기준 버전: **CrossWorld DEV BASE 0.1**
- 실행 파일: `Emuera.NET 1824+v24+EMv18+EEv56.exe`
- 실행 환경 기준: `test/ERA_CrossWorld_Runtime_Test_0.1.2/`

이 디렉터리는 현재 개발 중인 코드를 실제 Emuera에서 확인하기 위한 가변 작업장이다. 압축 파일로 내려받았다면 전체 내용을 한 디렉터리에 압축 해제한 뒤 위 EXE를 직접 실행한다.

## 확인 시나리오

1. 게임을 실행한다.
2. `HOME` 자택 화면이 표시되는지 확인한다.
3. 날짜 `1일`, 시각 `08:00`을 확인한다.
4. `[1] 잔다`를 선택하고 `2일 08:00`을 확인한다.
5. 다시 `[1] 잔다`를 선택하고 `3일 08:00`을 확인한다.
6. `[2] 나간다`를 선택하고 외부 미구현 화면을 확인한다.
7. `[0] 집으로 돌아간다`를 선택한다.
8. HOME 화면에서 `3일 08:00`이 유지되는지 확인한다.

## 입력 확인

- 숫자키 `1`, `2`, `0`으로 각 행동을 확인한다.
- 화면의 `[1]`, `[2]`, `[0]`을 마우스로 클릭해 같은 행동이 실행되는지 확인한다.
- 허용되지 않은 숫자나 잘못된 입력을 넣어도 크래시나 화면 파손 없이 현재 선택 화면으로 돌아오는지 확인한다.

## 결과 처리

- 실제 Emuera 실행에서 모든 항목을 확인한 경우에만 PASS로 판단한다.
- FAIL이면 `game/`을 직접 수정하지 않고 이 `dev/runtime/` 작업장에서 먼저 수정한다.
- PASS 후 별도 승격 작업으로 검증된 CSV/ERB 변경만 `game/`에 반영한다.
