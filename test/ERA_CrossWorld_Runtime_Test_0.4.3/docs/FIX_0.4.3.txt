ERA CrossWorld Runtime Test 0.4.3

Observed:
System.Collections.Generic.KeyNotFoundException:
The given key 'CWRT4_SHARED' was not present in the dictionary.

Diagnosis:
PluginManager.GetIntVar(name) directly indexes GetVarTokenDic()[name].
The ERH user-defined #DIM variable is not part of that dictionary in this runtime.

Changed test strategy:
- Direct PluginManager variable API -> built-in GLOBAL:0.
- Custom structured state -> PluginManager.GetDataTable("cwrt4_db").
- User-defined scalar/string exchange -> CALLSHARP reference parameters (already PASS).

This distinguishes supported bridge paths instead of treating every ERB symbol as a direct API variable.
