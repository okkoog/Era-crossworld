ERA CrossWorld Runtime Test 0.1.2
====================================

0.1.1 관찰 결과
- ASCII 40자 ≈ 한글 20자 ≈ 일본어 20자 ≈ 전각 20자 ≈ BOX(─) 20자
- BLOCK(█) 40자 ≈ ASCII 40자
- 따라서 현재 MS Gothic/TEXTRENDERER 조합의 시험 결과:
  ASCII/영문/숫자     = 1 half-width cell
  한글/일본어/전각   = 2 half-width cells
  ─/│ 계열           = 2 half-width cells
  █ 계열(시험된 █)   = 1 half-width cell

성능
- Compact map 100회: 213 ms (약 2 ms/map)
- 강제 렌더링 20회: 425 ms (약 21 ms/frame, 표시값 약 47 FPS)
- 이 단계에서는 성능 병목으로 판단하지 않는다.
- 메모리 증가는 단발 측정이라 누수 판정 불가.

0.1.2 목적
1. 메뉴를 INPUT에서 ONEINPUT으로 교체.
2. 숫자키 한 번만 눌러 즉시 입력되는지 독립 시험.
3. 버튼 클릭도 독립 시험.
4. 한글의 실제 표시폭까지 보정한 ASCII 지도에서 경계 정렬 확인.
5. ─/│를 2칸으로 취급하면 Unicode 박스 지도가 정상 연결되는지 확인.

TEST 3의 논리 표시폭
- 98 half-width cells

판정
- [1] 키보드 7 한 번(Enter 없이) -> PASS
- [2] [8] 마우스 클릭 -> PASS
- [3] 모든 | 세로 경계가 행마다 일치 -> PASS
- [4] 박스 모서리/세로선 연결 -> 사용 가능 여부 판단
