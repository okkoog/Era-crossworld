ERA CrossWorld Runtime Test 0.2.1

0.2 수정판.

발견된 문제
- RuntimeTest_020.ERB에서 #DIM I / #DIM N을 사용해
  Emuera 내장 변수명과 충돌 경고가 발생했다.
- 로드 화면에는 별도로 '해석 불가능한 행'이 있다고 표시됐지만,
  스크린샷에는 그 정확한 행 번호가 노출되지 않았다.

수정
- 모든 private/global 시험 변수명을 CWRT_ 접두어로 통일.
- I, N 등 짧은 내장/예약 가능 이름을 전부 제거.
- 벤치마크 로직은 동일한 목적을 유지.

테스트 순서
1. 우선 프로그램이 오류 없이 메뉴까지 로드되는지 확인.
2. [1] Standard Suite 실행.
3. 성공하면 [2] Stress.
4. [3] Sanity PASS 확인.
5. [4] VARSET 확인.

만약 0.2.1도 시작 단계에서 종료된다면:
- 생성된 emuera.log를 보내면 정확한 오류 행을 기준으로 수정한다.
