ERA CrossWorld Runtime Test 0.3.1

Observed in 0.3:
- SAVE time: 23 ms
- CHKDATA result: 0
- Then error: function @SHOW_SHOP not found

Diagnosis:
- SAVE itself succeeded.
- LOADDATA changes Emuera's system flow after loading.
- Immediately after load, @EVENTLOAD is called.
- If @EVENTLOAD is absent, Emuera transitions to @SHOW_SHOP.
- The clean CrossWorld skeleton intentionally has no @SHOW_SHOP.

Fix:
- Define @EVENTLOAD #ONLY.
- Verify all 50,000 restored saved integers inside the load event.
- Return to @SYSTEM_TITLE using BEGIN TITLE after verification.
