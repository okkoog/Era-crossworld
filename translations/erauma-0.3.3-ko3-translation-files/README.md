# EraUma 0.3.3-ko3 남은 원문 — 기존 번역 파일 형식

기존의 단어·문구 조각 JSON을 폐기하고, 현재 번역 파일과 같은 `.js`·`.kojo` 형식으로 다시 만들었습니다. 문장, 변수 삽입, 출력 배열, 조건 분기, 함수 및 대사 블록을 쪼개지 않고 전체 파일 안에 보존했습니다. 새 한국어 번역을 작성한 묶음은 아닙니다.

## 번역 작업

1. `files/`에서 원래 저장소 경로와 동일한 파일을 엽니다. [파일별 목록](FILES.md)에서 바로 열 수도 있습니다.
2. `[번역 대상]` 주석이 있는 함수/속성/대사 블록의 남은 일본어·중국어 문구를 한국어로 바꿉니다. 한 문장이 문자열 배열이나 변수 사이에 이어져 있으면 앞뒤 문맥을 함께 보고 번역합니다. 코드 때문에 나뉜 원래 출력 구조 자체는 유지합니다.
3. 이미 한국어인 부분은 다시 번역하지 않습니다. 표시되지 않은 함수는 주변 문맥과 정상적인 모듈 구조를 보존하기 위한 참조입니다. 표시할 수 없는 데이터 항목은 FILES.md의 대상 키를 기준으로 해당 파일에서 편집합니다.
4. 함수/속성 이름, `%YOU%`·`%CHARA%` 등의 토큰, `${...}` 표현식, require 경로, 조건식, 들여쓰기와 `.kojo` 구조는 유지합니다.
5. 번역한 파일을 같은 경로와 이름으로 돌려줍니다. JSON의 koreanText 칸을 채우는 절차는 없어졌습니다.

## 파일 위치와 합치기

- `files/sources/erauma/ere/i18n/ko-KR/`: 현재 적용된 한국어 모듈의 전체 파일. 기존 한국어를 그대로 두고 남은 원문을 번역합니다.
- `files/sources/erauma/ere/i18n/ja-JP/`, `zh-CN/`: 한국어 모듈이 상속하거나 참조하는 원본. FILES.md 및 주석에 표시된 함수/속성만 번역합니다. 파일 전체의 일본어를 모두 다시 번역할 필요는 없습니다. 완료 후 해당 부분을 한국어 모듈에 합치며, 일본어 언어팩을 덮어쓰는 용도가 아닙니다.
- 다른 `files/sources/erauma/ere/` 경로: 언어 모듈 밖에 남아 있는 이름·표시 문구의 원래 파일 형식.
- `files/ports/erauma-emuera/`: 실행기에 남은 영어 UI/오류 안내의 원래 `.js`·`.cs`·`.ERB` 파일. 표시된 문자열만 번역합니다.

전체 모듈을 보존하여 이미 적용된 번역과 게임 로직이 함께 보입니다. 번역 완료 후 표시된 부분의 변경만 수정판에 합칩니다. 이 작업 폴더를 통째로 게임에 덮어쓰지 않습니다. 검토 보류 위치의 빈 본문도 게임에 반영하지 않습니다.
