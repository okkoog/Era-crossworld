# EraUma 0.3.3-ko3 최종 한국어 override 작업 파일

이제 번역 원고와 최종 한국어 파일이 같은 파일입니다. `files/sources/erauma/ere/i18n/ko-KR/`에서 파일 하나를 번역하면 그 파일 자체를 실제 `ko-KR` 동일 경로에 사용할 수 있습니다. 번역된 일본어 파일에서 함수를 추출하거나 다른 형식으로 다시 조립하지 않습니다.

## 번역 방법

1. [작업 파일 목록](FILES.md)에서 파일을 엽니다.
2. `[번역 대상]` 표시가 붙은 실제 한국어 override의 남은 일본어·중국어만 한국어로 바꿉니다. 함수/속성/scene 전체 문맥을 보며 작업합니다.
3. 이미 한국어인 부분은 유지합니다. 함수명·scene key·변수·분기·`%YOU%`·`%CHARA%`·`${...}` 등 치환 표현식과 코드 구조도 유지합니다.
4. 같은 파일명과 경로로 완료본을 반환합니다. syntax/구조 검증 후 해당 파일을 동일 경로에 교체하고 residual을 재검사합니다.

## 미리 완료한 구조 작업

- 기존 `ko-KR` 파일 127개를 기반으로 원문이 남은 override를 보존하거나 현재 3.113의 누락 멤버를 추가했습니다.
- 없는 한국어 모듈 174개는 처음부터 `ko-KR` override로 만들었습니다.
- `timon/child/daily.js`에는 기존 한국어를 유지하고 `talk_2`·`talk_estrus` 전체 함수를 추가했습니다.
- `timon/child/ero.js`와 Timon entry의 `ero_child` 연결도 준비했습니다.
- 캐릭터 entry → Kojo entry → 언어 entry 연결과 보조 모듈 spread 연결을 함께 준비했습니다. 연결 파일은 최초 반영할 때 함께 복사합니다. 이후 개별 번역 파일은 그대로 교체합니다.
- 기존 완료 한국어 파일 108개도 변경 없이 함께 포함했습니다. [참조 파일 목록](REFERENCE_FILES.md)의 파일은 다시 번역하지 않습니다.
- `ja-JP`·`zh-CN` 번역 원고 폴더는 없습니다. 언어팩 외부 데이터/실행기 UI 109개 파일만 원래 경로와 형식을 유지합니다.

## 보존과 확인

- 한국어 경로 파일: 409개. 작업/연결 파일 301개 + 기존 완료 참조 108개.
- 기존 작업 기반 파일의 한국어 literal 해시 12,410개를 보존했습니다. 참조 파일은 원본 바이트와 동일합니다.
- JS와 KOJO 문법을 확인했고, 작업/연결 모듈 301개가 실제 KO entry에서 도달하는 것을 확인했습니다.
- 이전 residual 105,400개 원문 해시가 작업본에 남아 있음을 확인했습니다. 이 데이터는 누락·완료율·해시 검사 용도이며 번역 단위가 아닙니다.
- 기존 검토 보류 위치는 [별도 목록](HELD_LOCATIONS.md)에 남겼습니다. 해당 부분은 기존 한국어/원문 상속으로 유지하며, 빈 본문으로 게임 내용을 덮어쓰지 않습니다.
