## 번역 방법

1. [작업 파일 목록](FILES.md)에서 파일을 엽니다.
2. **재사용 감사는 완료되었다.** `[번역 대상]`을 곧바로 신규 번역하지 말고, 먼저 [TRANSLATION_REUSE_AUDIT.md](TRANSLATION_REUSE_AUDIT.md)에 확정된 old-KR 재사용 대상(B/C)을 현재 구조에 반영한다. 재사용 반영 후에도 남는 D/신규 항목만 새로 번역한다.
3. 이미 한국어인 부분은 유지합니다. 함수명·scene key·변수·분기·`%YOU%`·`%CHARA%`·`${...}` 등 치환 표현식과 코드 구조도 유지합니다.
4. 같은 파일명과 경로로 완료본을 반환합니다. syntax/구조 검증 후 해당 파일을 동일 경로에 교체하고 residual을 재검사합니다.
