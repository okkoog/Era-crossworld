## 외부 번역자 작업

JSON을 복사하여 `koreanText`만 채운다. `originalText`, ID, 원본 경로·함수 키·AST/YAML 주소는 보존한다. 원문의 치환 토큰과 앞뒤 공백을 유지한다. 일부 한국어가 섞인 항목은 기존 한국어를 유지하고 남은 원문만 번역한다.

번역한 파일을 같은 폴더 구조로 돌려주면 원본 위치를 대조해 수정판에 반영한다. 이 폴더는 게임 실행용 코드가 아니다. 이미 한국어인 본문과 제어용 CSV/코드 식별자는 다시 번역할 목록에 넣지 않았다.
