# 用游戏王讲解事件逻辑

by 无名路人

各种事件的触发其实是很自由的 只要想就可以在各种时点触发各种事件

以下用游戏王举例说明（？难道不是门槛更高了吗）

给不太懂的人举个例子 每回合内以下每个阶段开始时 结束时都可以放事件触发的判定

## 准备阶段

此阶段是游戏处理每回合开始时信息的过程 如果无事发生的话就不会显示内容

可以视作玩家前往训练员室之前 

（务必记得一回合是一周 但当然也可以当作一天开始来写事件）

## 主要阶段

此阶段是为玩家展示主界面 由玩家决定下一步的行动 

相当于玩家坐在训练员室里

这个阶段最好不要放事件 因为事件是被动的 这里还是主动权完全放给玩家 

（想放的尽量往前后移动一些 比如主阶开始就可以放到准阶结束 主阶结束就放到战阶开始）

## 战斗阶段

按玩家的决定 进行训练/比赛/调教/日常行动 并扣除一定精力代表时间

相当于离开训练员室

大部分的事件都在这里 其中的时点都很自由 行动前 行动中 行动后 只要想得到的时点都可以
  
## 主要阶段

行动结算完毕后会再度回到主界面 再由玩家继续决定下一步要去哪 

相当于出门完又回到训练员室

除了刚刚战斗阶段扣掉的时间以外与上一个主要阶段一样

## 战斗阶段

继续这样进行主要阶段跟战斗阶段的循环 直到时间扣光

某种意义上来讲 一个主阶+一个战阶构成的这一个扣时间小循环，就相当于在一周内过了一天

## 结束阶段

游戏再进行回合结束时信息的处理 就跟开始阶段差不多意思

相当于下班回家（？
