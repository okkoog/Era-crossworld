# eramegaten_p_kr

## 설치 방법

1. 본체 다운로드

2. 포크용 repo에서 resources 다운 후 Data 안에 붙여넣기

    https://gitgud.io/eraKR/eramegaten_p

3. 구상 번역 레포에서 다운 후 Data 안에 붙여넣기

    https://gitgud.io/cobaltmist/eramegatenpKOJO_KR

4. megaten p판 전용 MS굴림체 검색해서 설치

    or https://gitgud.io/eraKR/MS_GulimChe_Build 에서 자체적으로 빌드해 사용

    폰트 적용 실패시 Data\emuera.config의 인코딩을 UTF-8 with BOM으로 변경 후

    フォント名을 찾아서 フォント名:MS굴림체 로 변경할 것

    (해당 폰트를 제외한 폰트에 대한 레이아웃 정합성을 보장하지 않음)

### 권장 작업
