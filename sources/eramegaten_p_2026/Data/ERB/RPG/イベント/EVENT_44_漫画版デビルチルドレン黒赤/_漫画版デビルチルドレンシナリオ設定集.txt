;・ノルンの鍵/アナザーノルン
;　虹・青・金・白・緑・赤・紫の七種があり、うち虹以外は虹のコピー品である。
;　「お前たちはすべて揃うと勝てなくなると思っていたようだが、虹一本あれば十分だ……」
;　/
;　対応は以下の通り。
;　虹：デビルチルドレンたちが持っている
;　青：アイスランド・ダイアナ
;　金：アイスランド魔王ヘル
;　白：マーブルランド魔王のビビサナたちがそれを巡って争っている/漫画版では、ラセツオーが差し出してきて、フェンリルがサンドランドとの交渉にあたって持ち出してきた
;　緑：ファイアーランド魔王マモン
;　赤：フォレストランド魔王ベリアル
;　紫：サンドランド魔王イシス
;　/
;　漫画版では結局、金のツノをヘルから得て、白の鍵をイシスに献上して……おそらく天使勢力が緑と赤の鍵を得ているが、青と紫の鍵は登場していないはず。
;　というか赤と緑の鍵も登場はしてないと思う。
;　/
;　ツノとヒトミが引き合うという設定はオリジナルである。
;　/
;　で、虹以外の６本はなんであるの？という話。
;　ディープホールから直でセントラルランドに行ったとかあの辺も含みで展開巻いた影響とみる。
;　上述したが、「６本のツノ」は、このシナリオでは「反逆のツノ」として扱う。
;　暴虐の王への廃位の鍵、と。
;　この「反逆のツノ」、「アナザーノルン」が、シナリオクリア報酬な。
