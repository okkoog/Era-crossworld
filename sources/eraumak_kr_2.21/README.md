# EraUmaK

This repo is a project of translation [EraUma](https://gitgud.io/umaera/erauma) to Korean.

Base version: 2.21

리소스팩 사용방법: 메인화면의 리소스팩 버전을 눌러 리소스팩을 다운받은 후 game\res 폴더를 만든 뒤, res 폴더에 리소스를 넣어주세요.

리소스를 다 넣은 뒤에, res 덮어쓰기용 폴더 안에 있는 game 폴더를 복사해서 한판 game 폴더에 덮어씌워주면 됩니다.(일부 bgm이나 조교 배경용)


실행기(exe)는 [원본 레포](https://gitgud.io/umaera/erauma)의 release 페이지에서 erauma-with-engine-(버전명)-win-x64.7z 를 다운받은 뒤 ERA-Electron - 重量级ERA引擎.exe 파일을 최상위 폴더에 넣어주세요
