## [EraUma v1.34 (kuuga)](https://gitgud.io/umaera/erauma/-/releases/1.34)

_2025/4/4_

适配 [EraElectron v4.0.2 (x)](https://gitgud.io/umaera/engine/era-electron/-/releases/4.0.2) 与 [ere.app v1.0.9 (lipiah)](https://gitgud.io/umaera/engine/ere-app/-/releases/1.0.9) 及以上版本

### Added

* 新增好感护盾机制
  * 当好感提升后超出 600 上限时，超出部分会为该角色对玩家的好感增加护盾
  * 在好感降低时，好感护盾会先于好感被消耗
  * 好感护盾的数值提升遵循以下规则：
    * 提升一点好感护盾所需的溢出好感数量随好感护盾值的增加而线性增加
      * 不足部分仍然会提高一定的好感护盾
    * 当爱慕值高于 50 时，溢出好感提升好感护盾的数值随爱慕值的增加线性增加
* 在标题界面根据本地时间新增了角色的诞生日提示
* 为机伶金花增加了调教相关的特殊机制和相应口上
* 扩充了强敌列表并新增相关的技能

### Changed

* 现在角色扮演模式下将禁用【黑暗交易】选项
  * 已被惩戒的角色扮演存档不受影响
* 现在强敌将套用其立绘设定

## [EraUma v1.3 (kuuga)](https://gitgud.io/umaera/erauma/-/releases/1.3)

_2025/2/16_

适配 [EraElectron v3.5.0 (victory)](https://gitgud.io/umaera/engine/era-electron/-/releases/3.5.0)
与 [ere.app v1.0.6 (lipiah)](https://gitgud.io/umaera/engine/ere-app/-/releases/1.0.6) 及以上版本

### Added

* 新增照看机制
  * 所有人类角色和完成育成的角色（必须在殿堂周之后）可以照看育成中的角色
    * 玩家和该角色的好感度不能低于76（融洽）
    * 每次切换照看对象时好感度会下降25-50点（病娇角色的随机上限增加25*病娇等级）
  * 被照看的角色自主训练会有更好的效果
    * 自主训练时不生效的头衔加成在照看时会生效
    * 自主训练时的训练加成会加上照看者的相应训练加成
      * 如果照看者相应训练加成低于0就不上升
    * 此外，自主训练的训练加成还会额外提高50%
    * 自主训练获得的技能点数会按照所有训练加成的一半百分比上升
      * 被照看者获得的技能点数不会因该条加成而减少，即总训练加成低于0时不会减少获得的技能点数
  * 被照看的角色自主训练时可以提升训练设施等级
  * 被照看的角色自主训练时训练经验额外上升照看者相应训练加成的一半
    * 被照看者获得的训练经验不会因该条加成而减少，即照看者相应训练加成低于0时不会减少被照看者获得的训练经验
  * 每照看一次训练，被照看者对照看者的好感度上升15～25点，照看者对被照看者的好感度上升5～15点
  * （口上支持）增加实例方法 CustomizedMec.get_take_care_buff，口上作者可以通过重载它来实现在照看特定角色的特定训练时提供额外的训练加成
    * 桐生院葵照看快乐米可时训练加成额外提高20%
    * 㭴本理子照看苦涩糖衣和小小蚕茧时训练加成额外提高20%
  * 重做了部分角色专属特性
    * 【同舟共济（桐生院葵）】：增加效果「照看时训练效果+50%」
    * 【彻底管理主义（㭴本理子）】：增加效果「照看时训练效果+50%」
* 新增协同自主训练机制
  * 未被照看的角色在选择相同自主训练项目时有几率一起训练
    * 每个角色都有30%的概率与之前的角色一起训练
    * 最多有5个人一起自主训练
  * 每个自主训练者都会为协同训练增加5%的训练加成
    * 2个角色协同自主训练时，训练加成为10%
    * 5个角色协同自主训练时，训练加成为25%
  * 协同自主训练时不会受到训练员头衔等级影响，会受到夏合宿和海外远征的影响
  * 协同自主训练后，角色对彼此的好感度增加10～20+点，每多一个角色增加2点上限
    * 2个角色协同自主训练时，彼此好感度增加10～24点
    * 5个角色协同自主训练时，彼此好感度增加10～30点
* 在招募界面的育成情报预览增加了专属成就及条件信息
* 为荣进闪耀育成事件【经验之谈 · 三】增加了表现差分

### Changed

* 现在角色在资深年12月第四周结束时不再进行自主训练了
* 现在角色会因为弗隆K/P而从女性变为FUTA了
* 望族的招募事件链改为在访客招待室进行
  * 在赢得两次凯旋门赏并具有中坚及以上头衔（1,000声望以上）后，望族会出现在访客招待室，可以直接招募
  * 已达到条件但未招募望族的存档，望族会在加载并过回合后出现在访客招待室
  * 望族获得了各100的初始继承因子，以匹配其已育成传奇马娘的身份

### Fixed

* 修复了部分资源文件名错误
* 修复了物色对象不会强制出现在训练场的错误
* 修复了目白多伯专属称号【冷美人】的条件描述和判定错误
* 修复了乳头高潮不会被计入高潮总次数的错误
* 修复了因极值工具函数 get_extremum_entry 返回值与预期不符导致的逻辑错误
* 修复了马娘训练员在每个月第四周会显示收到0马币工资的错误
