# 0.3.3-ko3 한국어 재사용 반영과 외부 번역 이양

기록일: 2026-10-04. 사용자 요청은 판정을 끝낸 기존 한국어를 수정판에 적용하고 나머지를 외부 번역용 데이터로 분리해 나중에 합치는 것이다. Work에서는 배치마다 중단하는 제한을 적용하지 않는다. 새로운 한국어 게임 문장은 작성하지 않았다.

이번 추가분은 기존 2.21 literal 358개다: Timon 일상 98, 교육 88, 상태·구출 58, 게임 안내 45, 캐릭터 Daily/REC 69. 새 Kojo JS 17개는 원본 3.113 함수 39개를 literal 외에는 유지하고 미대응 함수 303개를 원본 참조로 상속한다. 캐릭터 entry 15개와 루트 entry를 연결했다. 루트의 사토노 다이아몬드 `67/99` 변형 구조는 독립 검사에서 발견해 원래대로 보존했다. 기존 GENERATED 영역과 이전 완료 기록은 바꾸지 않았다.

재사용 코드 커밋은 `8d3635c898d7a6ad21bfbd1af9e7785039d6df6d`다. 소스에 포함된 각 새 JSON과 `REUSE_HANDOFF_STATUS.json`에 직접 대응 원문·키·사유·검증과 해당 코드 커밋을 기록한다. 부분 적용과 구조상 재사용 불가는 일본어 fallback을 유지한다. 민감 제외는 재사용 원문 부재 판정과 구별하며 아동 성적 서술을 새로 추출하지 않았다.

- `korean-pack-summary.json`: 정확한 배포 DLL로 208개 검사 PASS. 한국어 선택·저장 복원, 기본·무작위·직접 외형과 재추첨, 새 게임·휴식·저장·새 세션 로드, 기존 4장면 15분기, 최신 random 상속 수, 신규 중립 시계 문구, 모든 캐릭터 entry의 객체·변형·함수·배열 구조와 `67/99` 경로를 확인했다.
- `korean-native-summary.json`: 실제 Emuera와 production Bridge에서 36개 검사 PASS. 기존 중단 경로인 초기값 외형 선택부터 메인 화면·휴식 후 복귀까지 격리 저장으로 진행했다. PNG 7개는 실행기 내부 canvas이며 사용자 화면 캡처가 아니다.
- `daily-edu-validation.json`: 186 literal 모두 기존 2.21 대응 함수에 정확히 존재하며 현재 AST·문자열 경계·기존 한국어 키·제외 본문이 보존된다.
- `kojo-validation.json`: 1,257개 구조·출처·연결 검사와 중립 실행 2개 PASS. 기존 REC 판정을 다시 조사하지 않고 적용 결과를 기록했다.
- `package-input-validation.json`: 작성기 입력의 합성 검사 23개 PASS. 실제 Kojo 목록의 일대일 대응과 누락·중복·잘못된 경로·다른 커밋·변경된 해시·편집된 번역 슬롯을 검사한다.
- `translation-handoff-validation.json`: 번역 도구의 고정 fixture 19개 PASS. JS·class·const·YAML 소유 슬롯, 한글/CJK 혼합 문구, 성별 metadata 오탐, 기존 판정 연결, 빈 번역본과 기존 중립 한국어 예제, 원문·placeholder·경계·ID 변경 거부, 합치기 충돌과 검토 계획 생성, 게임 원본 불변을 확인한다.

최종 한국어 소스는 `58107d55839f7f230ec559e101c32c23fe7230fa`이며 `erauma-ko`에 반영했다. 깨끗한 해당 커밋에서 외부 번역 JSON 192모듈·11,539슬롯을 생성했다. 한글/CJK 혼합 문구도 전체 literal로 보존하고 기존 한국어를 유지할 검토 표시를 붙였다. 인명·제목 후보는 별도로 표시한다. 제외는 2,314그룹의 metadata로 기록하며 슬롯 개수와 다른 단위다. 키별 기계 기록이 없는 상태는 `no_key_level_record` 등으로 분리하며 이미 완료한 영역을 재조사하거나 새 판정을 했다는 의미로 쓰지 않는다.

한국어 `.kojo` 43개는 원본 컴파일러로 새 폴더에 변환했다. 패키지 작성기는 실제 소스/생성 경로와 SHA256을 기록한다. 기존 고정 31개 제한을 제거했으며 ko1·ko2 재현도 유지한다. 최종 ZIP과 새 압축 해제본의 파일 해시, 비한국어 게임 파일 및 ko2와 동일한 EXE·DLL, 최신 ko2 저장 복사와 원본 불변은 별도 최종 배포 receipt로 확인한다.

번역 도구는 원문 ID·AST/YAML 위치·해시·placeholder와 동적 경계 정보를 담은 모듈별 JSON을 만든다. 외부 작업자는 `koreanText`만 채운다. 검증·합치기 미리보기는 게임 파일을 수정하지 않으며 새로운 상속 override의 실제 적용은 별도 검토 대상으로 남긴다. 전체 번역이나 새 FPS 측정·전체 사람 직접 플레이의 완료를 뜻하지 않는다. ko2의 화면 처리와 네 DLL은 그대로 사용한다.
